# Atelier Pro

Application de peinture numérique pour iPad, iPhone et PC, en français : pinceaux, calques, lasso, guide de visage, symétrie, export PNG/JPEG.

**Ouvrir l'application :** https://lethuret.github.io/atelier-pro/

**Installer sur iPad ou iPhone :** ouvrez l'adresse ci-dessus dans Safari, touchez Partager, puis « Sur l'écran d'accueil ». L'application s'ouvre en plein écran et fonctionne hors ligne. Les dessins restent sur l'appareil.
